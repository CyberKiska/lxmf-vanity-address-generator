# Deviation register

This file lists every intended difference between the Go v1 command-line tool and the Rust v2 tool. Each row has a stable ID, the area it affects, what Go v1 does, what Rust does, and why they differ. *Unavoidable* means the language, runtime or platform makes the Go behavior impossible to copy. *Deliberate* means the difference was chosen, and the Decision column names the owner decision that allows it. *Pinned by* names the unit test or conformance case that fails if the Rust behavior changes. *Status* moves from `planned` through `implemented` to `verified`. Entries are never deleted; a difference that disappears is marked as such, and a difference found by a test that has no entry here is a defect.
