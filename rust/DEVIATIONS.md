# Deviation register

This file lists every intended difference between the Go v1 command-line tool and the Rust v2 tool. Each row has a stable ID, the area it affects, what Go v1 does, what Rust does, and why they differ. *Unavoidable* means the language, runtime or platform makes the Go behavior impossible to copy. *Deliberate* means the difference was chosen, and the Decision column names the owner decision that allows it. *Pinned by* names the unit test or conformance case that fails if the Rust behavior changes. *Status* moves from `planned` through `implemented` to `verified`. Entries are never deleted; a difference that disappears is marked as such, and a difference found by a test that has no entry here is a defect.

| ID | Area | Go v1 behavior | Rust behavior | Kind | Decision | Platforms | Pinned by | Status |

| `DEV-fips-on-debug` | `GODEBUG=fips140=on` or `debug` | Accepted. The search runs normally; `debug` also prints self-test lines on stderr. | Refused before any cryptographic work: exit 1 with "FIPS 140-3 mode was requested (GODEBUG=fips140=<on\|debug>); this build has no FIPS 140-3 validated cryptographic module"; `<on\|debug>` is the requested value. | Deliberate | R-4 (owner, 2026-11-20) | all | unit tests `only_is_refused_with_the_self_test_message`, `on_and_debug_are_refused_naming_the_requested_value` (`godebug.rs`); conformance case pending | planned |
| `DEV-fips-unknown` | `GODEBUG=fips140=<unknown value>` | The Go runtime panics before `main` with a stack trace; exit 2. | A one-line diagnostic without a trace on stderr, empty stdout; exit 2. Only the text differs. | Deliberate | R-4 (owner, 2026-11-20) | all | unit test `unknown_setting_fails_before_parsing_with_exit_2` (`godebug.rs`); conformance case pending | planned |
| `DEV-workers-default` | Default worker count | `GOMAXPROCS`: honors the `GOMAXPROCS` environment variable and, since Go 1.25, Linux cgroup CPU limits (rounded up). | `std::thread::available_parallelism()` clamped to 1 to 256, and 1 if the call fails. The `GOMAXPROCS` variable is ignored. A fractional cgroup CPU limit may be rounded down, where Go rounds it up. The value shows in the `--help` text (`(default N)`) and is the default of `--workers`. | Unavoidable | none needed | all | `args::tests::default_workers_come_from_the_caller_and_are_in_range` | implemented |
| `DEV-version-text` | `--version` output | Names the Go toolchain: `lxmf-vanity <version> (go1.x.y <goos>/<goarch>)`. | Names the Rust compiler in the same position: `lxmf-vanity <version> (rustc 1.x.y <goos>/<goarch>)`, with the same `<goos>/<goarch>` names and no build-machine text. | Unavoidable | none needed | all | unit tests `version_text_*` (`version.rs`); `scripts/smoke_artifact.py` | planned |
| `DEV-entropy-failure` | Failure of the operating system's random source | Go 1.24 and later terminate the process. | The failure is returned as an error. A winner that was already found can still be saved before the tool exits with a failure status. | Deliberate | pending owner agreement | all | not yet pinned | planned |
| `DEV-linux-static` | Linux binary linkage | PIE executable with an ELF interpreter, so it needs a glibc-based system. | Static musl executable with no ELF interpreter; it also runs on musl-based systems. | Deliberate | R-6 (owner, 2026-11-20) | Linux | not yet pinned | planned |
| `DEV-inspect-conflict-order` | `--inspect` combined with other flags | Reports `--inspect cannot be combined with --<name>` for one of the conflicting flags, chosen in map order, so the name varies from run to run when several are given. | Reports the first conflicting flag in command-line order. Same message format, same exit status 2; only the name is deterministic. | Deliberate | none needed (harmless) | all | `args::tests::inspect_reports_the_first_conflicting_flag_in_command_line_order` | implemented |
| `DEV-pattern-lowercase-unicode` | `--prefix` or `--postfix` containing non-ASCII text | Lowercases with Go's Unicode tables (Unicode 17.0.0 in the reference toolchain) before the length and hex checks. | Same algorithm, using Rust's Unicode tables. The 21 code points whose lowercase form Rust knows and Go 1.27.4 does not (U+A7DD, U+A7E2, U+AB6C, U+AB6D and 17 in U+1DF40 to U+1DF7E) shrink by one byte in Rust only. Effect: a pattern of exactly those characters whose lowercase length straddles 32 bytes gets the hex-character message in Rust and the 1-32 length message in Go; both exit 2. Every other input matches, checked over all Unicode scalar values and invalid bytes. | Unavoidable | none needed | all | `args::tests::patterns_are_lowercased_like_go_before_validation` | implemented |
| `DEV-windows-reserved-extension` | Windows path whose last element is a reserved device name with an extension or trailing spaces (`CON.txt`, `NUL.`, `COM1 `), for `--inspect` and the output paths | Go asks the system (`RtlIsDosDeviceName_U`). Since Windows 11 a reserved name with an extension is an ordinary file name, so Go accepts `CON.txt` there and refuses it on older systems. | Refused with `output path must name a file` on every Windows version. The command-line crate cannot make that system call (it forbids `unsafe`), and refusing is the safe answer where the name would open a device. Plain reserved names (`NUL`, `COM1`, `CONIN$`) and every Unix path behave as in Go. | Deliberate | pending owner agreement | Windows | unit test `windows_reserved_names_with_extension_or_spaces_are_refused` (`target_path.rs`); native Windows run awaiting owner verification | planned |
